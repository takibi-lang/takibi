## Why it exists

The Takibi compiler is licensed under the GPLv3, and it stays so. Programs
compiled with it must not become GPLv3 works merely because they were
compiled with it. When the compiler translates a program, the object code
it writes contains code that comes from the compiler's own source and not
from the program: generated region operations (`lib/region_builtin.ml`),
code generated from `protocol` declarations, bounds and initialization
checks, intrinsic lowerings, and similar templates. Without this
permission, that generated code could be read as a copy of a GPLv3 work.
This exception removes that reading, in the way the GCC Runtime Library
Exception and the Bison exception do for their tools.

## Definitions

- **"Compilation Process"** means running the Takibi compiler (the
  contents of `bin/` and `lib/`, and any modified version of them) on
  input source files to produce object code, assembly, LLVM IR or any
  other output, including the outputs of its `--facts` and `--generate` options.
- **"Target Code"** means any output of a Compilation Process, to the
  extent it is generated by the compiler rather than copied from the
  input source files.
- **"Runtime Support Files"** means the following files, which compiled
  user programs link to run on Linux:
  `linux_user/common_linux/startup.S`,
  `linux_user/common_linux/syscall.S`,
  `linux_user/common_linux/print.tkb`,
  `linux_user/common/runtime.tkb`,
  `linux_user/common/print.tkb` and
  `kernel/printk/number.tkb` (which `linux_user/common/print.tkb` uses),
  together with the Target Code compiled from them. The copyright holder
  may add files to this list in a later version of this exception.

## Grant of additional permission

You may convey Target Code, and works combining Target Code with Runtime
Support Files, under terms of your choice, consistent with the licensing
of the input source files, even if the Target Code or the Runtime Support
Files contain material from the Takibi compiler or this repository that is
otherwise covered by the GPLv3.

## What it does not cover

- The compiler itself. Conveying the Takibi compiler, or a modified
  version of it, remains subject to the GPLv3.
- Input source files. The license of each source file you compile is its
  own. In particular, the Takibi kernel (`kernel/`, apart from the one
  file named above) and any file of this repository that you compile as
  part of your program, other than the Runtime Support Files, keep the
  GPLv3; compiling them does not change that.
- The other tools of this repository (`scripts/`, the model files and
  the tests), which remain under the GPLv3 alone.

## Removal

When you modify a covered file, you may remove this permission from your
modified version, as section 7 of the GPLv3 allows; you may then not
convey the modified compiler's output under this exception.
