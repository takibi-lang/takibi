About

Takibi is a research systems language and compiler for building a Linux-ABI-compatible kernel. It explores lifting kernel failures into compile-time errors with refinement types and affine ownership.

This demo runs the same AArch64 userspace and ext2 image on QEMU and Raspberry Pi 5. BusyBox httpd exercises process creation, virtual memory, Linux syscalls, filesystem I/O, and networking.
